# LT Clans Free

Plugin de clãs para servidores Minecraft, edição Free.

## Pré-lançamento identificado

- **Versão interna:** `0.2.0-alpha.3`
- **Status:** Alpha — versão de testes, não estável
- **Comando principal:** `/clan`
- **Aliases:** `/cla`, `/clas`
- **Ajuda:** `/clan ajuda`
- **Permissões declaradas:** `ltclans.jogar` (todos), `ltclans.admin` (operadores)
- **Autor declarado:** LT Plugins
- **API declarada no plugin.yml:** `26.3`

> Atenção: a compatibilidade real com versões do Minecraft e servidores Paper/Spigot/Purpur ainda precisa ser confirmada em teste. O valor de `api-version` foi transcrito do arquivo fornecido e não é garantia de compatibilidade.

## Instalação (após disponibilização do JAR)

1. Faça backup do servidor.
2. Confira a compatibilidade com a versão do servidor.
3. Coloque o arquivo JAR na pasta `plugins/`.
4. Reinicie o servidor e confira o console.
5. Use `/clan ajuda` para conhecer os comandos.
